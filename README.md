# Stream Monitor Relay

A minimal, lightweight Python daemon designed to work in tandem with `yt-channel-monitor`. It reads the stream state from `active_lives.json` and automatically relays active Twitch and YouTube streams to a local RTMP server using `streamlink` and `ffmpeg`.

## Features

* **Zero-Dependency Architecture:** Stripped of all third-party Python packages (no Flask, no Requests). Relies entirely on the Python standard library and system binaries.
* **Intelligent Priority Routing:** Differentiates between "Main" channels and "Collab" channels. Automatically intercepts and overrides a collab stream if a main channel goes live. Main channels are not terminated unless another main channel stream begins.
* **Smart Cooldown Cache:** Implements a local 150-second blacklist for streams that terminate naturally or crash. This bypasses the state-cleanup delay from the upstream monitor, allowing the relay to instantly snap to the next available stream.
* **Hands-Free Operation:** No manual overrides or UI management required. State is completely synchronized with `active_lives.json`.

## Prerequisites

Ensure the following binaries are installed and accessible in your system's PATH:
* `python` (>= 3.10)
* `ffmpeg`
* `streamlink`

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/shmilyhua/stream-monitor-relay.git
   cd stream-monitor-relay
   ```

2. Install dependencies using `uv`:
   ```bash
   uv venv --python 3.13
   uv sync
   ```

3. Configuration:
   Create a `config.json` file in the root directory. Link the `ACTIVE_LIVES_FILE` to the output generated by your `yt-channel-monitor` instance.

   ```json
   {
       "ACTIVE_LIVES_FILE": "/absolute/path/to/yt-channel-monitor/active_lives.json",
       "TARGET": "rtmp://localhost/live/stream",
       "TWITCH_OPTS": "--stream-sorting-excludes \">720p60\"",
       "TWITCH_QUALITY": "720p60,720p,best",
       "COOKIES_FILE": "/absolute/path/to/youtube_cookies.txt",
       "TWITCH_CONFIG_FILE": "/absolute/path/to/config.twitch",
       "MAIN_CHANNELS": [
           "神楽めあ / KaguraMea",
           "さぶめあちゃんねるっ!",
           "汚い方の神楽めあ【公式】",
           "神楽めあ"
       ]
   }
   ```

## Usage

Run the script to start the monitoring loop and the Flask web UI:
```bash
uv run stream.py
```

## Logic Overview

1. **State Polling:** The script polls `active_lives.json` every 10 seconds.
2. **Priority Evaluation:** If multiple streams are active, it selects the highest priority stream (Main > Collab). If priorities are tied, it selects the stream with the newest timestamp.
3. **Execution:** Pipes the selected stream through `streamlink` into `ffmpeg`, pushing it to the defined RTMP `TARGET`.
4. **Cooldown Application:** If the stream drops or the process crashes, the URL is added to a 150-second local blocklist, forcing the script to evaluate the next best available stream immediately.
